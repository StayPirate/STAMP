# Specification Review Archive

This directory preserves historical outputs from the retired bulk
specification-review workflow. Each Markdown file records reviewer findings
for the document named by the file.

These records are snapshots, not a live quality dashboard. Their status,
counts, and review dates are not maintained automatically and MUST NOT be used
to determine whether a specification is current, complete, or ready for
implementation. Validate every recorded finding against the current owning
document before acting on it.

Current specification review is performed by the specialized read-only
reviewers listed in `.opencode/README.md`. The applicable primary agent invokes
them according to `AGENTS.md`, evaluates every finding under Guardrail 26, and
owns any approved repository changes through the normal issue and pull-request
workflow.
